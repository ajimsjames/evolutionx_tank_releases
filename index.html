Flashing Guide

Step-by-step instructions for Motorola Edge 50 (tank)

1

Reboot to Fastboot

adb reboot bootloader
2

Flash Recovery Partitions

fastboot flash recovery recovery.img
fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash dtbo dtbo.img
fastboot reboot recovery
3

Format Data & Sideload ROM

In Recovery: Select Factory reset > Format data/factory reset. Then select Apply update > Apply from ADB and run:

adb sideload EvolutionX-17.0-20260911-tank-12.2-Unofficial.zip
4

Reboot to System

Select Reboot system now. Welcome to Evolution X 17!

!

Not Recommended

Dirty flashing without formatting user data is not recommended as it can cause unexpected system errors, bootloops, app crashes, or permission conflicts. For maximum stability and performance, always perform a Clean Flash.

1

Reboot into Recovery

adb reboot recovery
2

Sideload New Update ZIP (Without Wipe)

Navigate to Apply update > Apply from ADB and run:

adb sideload EvolutionX-17.0-20260911-tank-12.2-Unofficial.zip
3

Reboot

Select Reboot system now without performing a data wipe.
